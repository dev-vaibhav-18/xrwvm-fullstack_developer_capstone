
# fullstack_developer_capstone

## Repository Name
`xrwvm-fullstack_developer_capstone`

## Project Name
Full Stack Developer Capstone — Car Dealership Application

## Project Description
This project is a full-stack car dealership application developed as part of the IBM Full Stack Software Developer Capstone project.

The application provides a dealership interface where users can explore dealerships, view dealer details, register and log in, and submit dealership reviews.

## Technologies Used
- Frontend: React.js, HTML, CSS, Bootstrap
- Backend: Python and Django
- Database: MongoDB
- API communication: REST APIs

## Project Features
- User registration and login
- View car dealerships and dealership details
- Filter dealerships by state
- View and submit dealership reviews
- Analyze review sentiment
- Display car makes and models
